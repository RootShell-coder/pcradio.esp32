## Кнопки

Каждая кнопка подключается между своим GPIO и GND. Внешнее напряжение на
кнопочные входы подавать не нужно. Firmware использует:

- внутренний pull-up;
- опрос каждые 5 мс без GPIO ISR;
- debounce из четырёх отсчётов, то есть 20 мс;
- повтор только для VOL− и VOL+ после задержки 500 мс, затем каждые 100 мс.

События проходят через общий control ingress с источником
`CONTROL_SOURCE_GPIO`. Кнопки не вызывают player, Flash или сетевые функции
непосредственно.

## Силовые выходы

GPIO8 и GPIO18 являются только логическими управляющими сигналами. Усилитель и
обмотку реле нельзя питать от GPIO. Требуются внешние MOSFET-ключи, общий GND,
защитный диод реле и питание нагрузки.

После `power_control_init()` оба выхода принудительно устанавливаются в LOW.
При включении сначала активируется AMP_POWER, firmware ждёт 6 секунд и готовый
PCM, затем включает SPEAKER_RELAY. При выключении реле снимается раньше питания
усилителя. Это уменьшает щелчки и защищает акустический выход.

## STATUS_WLED

GPIO2 предназначен для внешней цепочки из пяти адресных LED:

1. PWR;
2. AMP;
3. SPK;
4. WIFI;
5. BUFFER (BUF).

### Цветовая сигнализация

Порядок индикаторов: **PWR → AMP → SPK → WIFI → BUFFER**.
«Дыхание» означает плавное изменение яркости с периодом 3 секунды.
Неактивные индикаторы погашены, белый цвет не используется.

| Индикатор | Цвет и режим | Значение |
| --- | --- | --- |
| PWR | зелёный постоянный | устройство готово |
| PWR | жёлтое дыхание | загрузка или выдержка включения усилителя |
| PWR | фиолетовое дыхание | доступна подтверждённая более новая прошивка |
| PWR | приглушённый фиолетовый постоянный | ожидание или переход в ожидание |
| PWR | красный постоянный | ошибка управления питанием |
| AMP | зелёный постоянный | выход питания усилителя включён |
| AMP | жёлтое дыхание | выдержка после включения питания усилителя |
| AMP | погашен | выход питания усилителя выключен |
| SPK | зелёный постоянный | выход управления реле акустики включён |
| SPK | погашен | выход управления реле акустики выключен |
| WIFI | зелёный постоянный | подключение установлено, сигнал достаточный |
| WIFI | жёлтый постоянный | слабый сигнал или уровень сигнала недоступен |
| WIFI | жёлтое дыхание | подключение или переподключение к Wi-Fi |
| WIFI | фиолетовый постоянный | режим точки доступа для настройки Wi-Fi |
| WIFI | погашен | ожидание или переход в ожидание |
| BUFFER | зелёный постоянный | запас звука в буфере не менее 2 секунд |
| BUFFER | жёлтый постоянный | запас от 0,25 до менее 2 секунд либо битрейт пока неизвестен при непустом буфере |
| BUFFER | жёлтое дыхание | подключение к станции или начальная буферизация |
| BUFFER | красный постоянный | пустой буфер, запас менее 0,25 секунды или ошибка воспроизведения |
| BUFFER | погашен | STOP, ожидание, недоступная станция или неподдерживаемый формат |

WIFI оценивает уровень сигнала RSSI. Жёлтый цвет включается при RSSI ≤ −70 dBm,
зелёный возвращается при RSSI ≥ −65 dBm. Между этими порогами сохраняется
предыдущее состояние, чтобы цвет не менялся от небольших колебаний сигнала.

BUFFER оценивает запас времени воспроизведения по объёму данных и битрейту.
При подключении и начальной буферизации показывается жёлтое дыхание.
Во время переподключения потока цвет определяется оставшимся запасом звука.
Смена состояния WIFI и восстановление BUFFER подтверждаются в течение
примерно 1 секунды. Критическое состояние BUFFER показывается без этой задержки.

Предложение отката на старую прошивку не включает фиолетовое дыхание PWR.
При обработке ИК-команды яркость PWR кратковременно увеличивается примерно
на 120 мс, основной цвет сохраняется.

AMP и SPK показывают состояние управляющих выходов. Обратной связи о
фактическом включении усилителя или срабатывании реле у этих индикаторов нет.

### Подключение

Цепочка WLED подключается к GPIO2 через 74AHCT1G125 и последовательный
резистор 330 Ом. Питание светодиодов: 5 В, GND общий с ESP32.
По питанию установлен конденсатор 1000 мкФ. GPIO2 передаёт только данные.

GPIO21 используется для PWM подсветки дисплея.

## Аудиовыход

Используется Philips I2S без MCLK:

- GPIO12 → BCLK;
- GPIO11 → WS/LRCK;
- GPIO10 → DIN UDA1334A;
- GPIO9 → MUTE.

GPIO9 устанавливается в HIGH при инициализации, остановке и аварийном
завершении I2S.

## Проверка на устройстве

Безопасные read-only проверки:

- `GET /api/power` показывает состояния AMP_POWER, SPEAKER_RELAY,
  backlight PWM и WLED;
- для WLED должны быть `ready=true` и `errors=0`; счётчик `transmissions`
  увеличивается при изменении индикации, включая дыхание;
- `GET /api/ir` должен возвращать `receiver.ready=true`;
- `GET /api/player/state` с растущим `audio.pcm_write_count` подтверждает
  работу I2S GPIO9–GPIO12.
