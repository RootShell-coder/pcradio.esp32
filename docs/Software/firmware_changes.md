# Изменения прошивки PCRadio-ESP32

## 2.3.2

- Переработана индикация пяти WLED с сохранением порядка PWR, AMP, SPK,
  WIFI и BUFFER. Неактивные индикаторы теперь погашены, белый цвет исключён.
- PWR показывает готовность зелёным, загрузку жёлтым дыханием, режим ожидания
  приглушённым фиолетовым и доступную новую прошивку фиолетовым дыханием.
  Предложение отката на старую версию не включает индикацию обновления.
- AMP и SPK показывают включённые управляющие выходы зелёным. Во время
  выдержки включения усилителя AMP плавно дышит жёлтым.
- WIFI отображает подключение и уровень сигнала RSSI вместо мощности
  передатчика: зелёный при хорошем сигнале, жёлтый при слабом, жёлтое дыхание
  при переподключении и фиолетовый в режиме точки доступа.
- BUFFER оценивает запас звука по битрейту: зелёный от 2 секунд, жёлтый
  от 0,25 до 2 секунд, красный при меньшем запасе или пустом буфере.
  При начальной буферизации включается жёлтое дыхание, при STOP индикатор гаснет.
- Добавлены сглаживание смены состояний и гистерезис RSSI для уменьшения
  мельтешения. Период дыхания составляет 3 секунды; в ожидании WIFI и BUFFER
  погашены.

### Индикация WLED

Порядок светодиодов на ленте: **PWR → AMP → SPK → WIFI → BUFFER**.

| Индикатор | Состояние                                                       | Индикация                          |
| --------- | --------------------------------------------------------------- | ---------------------------------- |
| PWR       | Устройство готово                                               | Зелёный постоянный                 |
| PWR       | Загрузка / выдержка включения усилителя                         | Жёлтое дыхание                     |
| PWR       | Доступна подтверждённая более новая прошивка                    | Фиолетовое дыхание                 |
| PWR       | Режим ожидания / переход в ожидание                             | Приглушённый фиолетовый постоянный |
| PWR       | Ошибка управления питанием                                      | Красный постоянный                 |
| AMP       | Питание усилителя включено                                      | Зелёный постоянный                 |
| AMP       | Выдержка после включения                                        | Жёлтое дыхание                     |
| AMP       | Питание усилителя выключено                                     | Погашен                            |
| SPK       | Выход управления реле включён                                   | Зелёный постоянный                 |
| SPK       | Выход управления реле выключен                                  | Погашен                            |
| WIFI      | Подключение установлено, сигнал достаточный                     | Зелёный постоянный                 |
| WIFI      | Слабый сигнал или RSSI недоступен                               | Жёлтый постоянный                  |
| WIFI      | Подключение / переподключение                                   | Жёлтое дыхание                     |
| WIFI      | Режим точки доступа / устройство не настроено                   | Фиолетовый постоянный              |
| WIFI      | Режим ожидания                                                  | Погашен                            |
| BUFFER    | Запас звука не менее 2 секунд                                   | Зелёный постоянный                 |
| BUFFER    | Запас от 0,25 до 2 секунд или битрейт ещё неизвестен            | Жёлтый постоянный                  |
| BUFFER    | Пустой буфер, запас менее 0,25 секунды или ошибка плеера        | Красный постоянный                 |
| BUFFER    | Подключение к станции / начальная буферизация                   | Жёлтое дыхание                     |
| BUFFER    | STOP, ожидание, станция недоступна или формат не поддерживается | Погашен                            |

Период дыхания — 3 секунды. Предупреждение WIFI включается при RSSI ≤ −70 dBm
и снимается при RSSI ≥ −65 dBm. Изменения WIFI и восстановление BUFFER
подтверждаются в течение 1 секунды; критический запас BUFFER показывается
без этой задержки. При подключении к станции BUFFER показывает буферизацию,
даже если буфер ещё пуст. AMP и SPK отражают команды на управляющих выходах,
а не физическую обратную связь. Белый цвет не используется.

## 2.3.1

- Выполнен переход на ESP-IDF 5.5.5. Сборка проверяет версию SDK и использует
  соответствующее окружение разработки.
- Устранён обход регулировки громкости при обработке больших PCM-блоков,
  в том числе Opus: звук обрабатывается частями без сброса состояния эффектов.
- Регулировка громкости перенесена после всех звуковых эффектов, чтобы их
  усиление также ограничивалось выбранным уровнем громкости.
- Усилена защита аудиовыхода при обрывах потока: контролируются паузы в выдаче
  PCM, исключено воспроизведение устаревшего отсчёта после длительного GAP.
- При ошибках MP3 вместо повторения прошлого кадра выполняется переход к
  тишине с плавным восстановлением. Добавлены проверки размеров PCM-блоков
  MP3 и Opus; неподдерживаемые форматы не передаются в I2S без ослабления.
- Исправлено возобновление пользовательской станции кнопкой PLAY: станция
  выбирается по сохранённому идентификатору через очередь команд плеера.

## 2.2.9

- Добавлен audio gap guard для подавления громких щелчков при пропадании и
  восстановлении потока, повторном подключении и ошибках декодеров.
- Реализованы управляемые fade-out/fade-in, программный PCM MUTE и аппаратное
  управление MUTE усилителя при смене или восстановлении аудиопотока.
- Исправлена кнопка MUTE: звук отключается немедленно, команда больше не ждёт
  блокирующую запись I2S, а WebUI не переходит в состояние «Нет устройства».
- Снятие MUTE выполняется на первом корректном PCM-кадре с плавным набором
  громкости.
- Исправлена обработка ICY-метаданных: декодируются percent-encoded строки и
  удаляются служебные маркеры `AETrim*` и `AudioTrim*`.
- Подтверждение работоспособности станции и локальная статистика сохраняются
  при остановке, между переключениями каналов и во время MUTE. Подтверждённые
  каналы больше не становятся недоступными после обновления прошивки.
- Исправлено отображение WebUI в Windows 11: уменьшена насыщенность шрифта,
  скорректированы размеры элементов навигации и выпадающих списков.
