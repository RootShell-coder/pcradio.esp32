# PCRadio ESP32

Интернет-радиоприёмник на базе ESP32-S3 с управлением через встроенный
web-интерфейс.

![PCRadio 2.0](docs/PCRadio-v2.0.0.png)

Перед первым включением установите программное обеспечение по
[инструкции по прошивке устройства](docs/Software/firmware.md).

## Аппаратная платформа

Проект разработан и проверен на плате **EST-ESP32-S3-DevKit N16R8**:

- ESP32-S3, два ядра Xtensa LX7 до 240 МГц;
- 16 МБ Quad SPI Flash;
- 8 МБ Octal SPI PSRAM;
- I2S: `BCK — GPIO12`, `LRCK — GPIO11`, `DATA — GPIO10`;
- управление MUTE усилителя или ЦАП: `GPIO9`.

[Распиновка используемой платы](docs/Hardware/EST-ESP32-S3_pinout.png).

[Схема подключения ESP32-S3 к модулю ЦАП CJMCU/UDA1334A](docs/Wiring/esp32s3_uda1334a_wiring-preview.png).

### Совместимые аналоги

Готовые бинарные файлы рассчитаны на ESP32-S3 с **16 МБ Flash и 8 МБ Octal
PSRAM**. Прямыми аналогами являются:

| Плата                                                                                                                                            | Совместимость | Примечание                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------- | ----------------------------------------------------------------------- |
| [Waveshare ESP32-S3-DEV-KIT-N16R8](https://docs.waveshare.com/ESP32-S3-DEV-KIT-N8R8)                                                             | полная        | Та же память, встроенная антенна, GPIO9–GPIO12 доступны                 |
| [Waveshare ESP32-S3-DEV-KIT-N16R8-U](https://docs.waveshare.com/ESP32-S3-DEV-KIT-N8R8)                                                           | полная        | Та же память и внешняя Wi-Fi-антенна                                    |
| Плата с модулем [ESP32-S3-WROOM-1-N16R8](https://www.espressif.com/sites/default/files/documentation/esp32-s3-wroom-1_wroom-1u_datasheet_en.pdf) | условная      | Подходит, если выведены GPIO9–GPIO12 и сохранена указанная схема I2S    |
| Плата с модулем ESP32-S3-WROOM-1U-N16R8                                                                                                          | условная      | Аналог с разъёмом внешней антенны; требуется проверить доступность GPIO |

Платы N8R8, N8R2, N8, ESP32-S3 без PSRAM и классический ESP32 несовместимы с
готовым комплектом бинарных файлов. Платы с другим объёмом или типом Flash/PSRAM
могут использовать исходный код проекта только после отдельной настройки, сборки
и проверки; текущие `bootloader.bin` и `partition-table.bin` для них применять
нельзя.

### Теоретически совместимые платы с меньшей памятью

Следующие варианты **не тестировались** с PCRadio. Это возможные платформы для
отдельной сборки, а не замена платы, совместимая с готовой прошивкой:

| Плата                                                                                                                                                   | Память                 | Оценка и необходимые изменения                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Espressif ESP32-S3-DevKitC-1-N8R8](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/index.html)                   | 8 МБ Flash, 8 МБ PSRAM | Наиболее вероятный вариант. Нужны разметка на 8 МБ, отдельная сборка и полная первичная прошивка.                                                                              |
| [Espressif ESP32-S3-DevKitC-1U-N8R8](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/index.html)                  | 8 МБ Flash, 8 МБ PSRAM | То же, но с разъёмом внешней антенны.                                                                                                                                          |
| [Waveshare ESP32-S3-DEV-KIT-N8R8](https://docs.waveshare.com/ESP32-S3-DEV-KIT-N8R8)                                                                     | 8 МБ Flash, 8 МБ PSRAM | Вероятно, сохранит текущую модель аудиобуферов; потребуется разметка на 8 МБ и отдельная сборка.                                                                               |
| [Espressif ESP32-S3-DevKitC-1-N8R2 / DevKitC-1U-N8R2](https://docs.espressif.com/projects/esp-idf/en/v5.0.2/esp32s3/hw-reference/esp32s3/user-guide-devkitc-1.html) | 8 МБ Flash, 2 МБ PSRAM | Экспериментальный вариант. Потребуются уменьшение сжатого буфера, пересмотр памяти декодеров и DSP, а также новая разметка. Стабильность FLAC, Vorbis и Opus не гарантируется. |
| [Adafruit ESP32-S3 Feather](https://learn.adafruit.com/adafruit-esp32-s3-feather)                                                                       | 4 МБ Flash, 2 МБ PSRAM | Предельный экспериментальный вариант: нужны переназначение GPIO, сильное сокращение разделов и буферов. Текущая двухслотовая OTA-схема вместе с WebUI не помещается.           |

Варианты без PSRAM не рассматриваются: текущая архитектура использует внешнюю
память для сжатого потока и рабочих буферов. Для плат с 2 МБ PSRAM потребуется
отдельный профиль сборки; уменьшать память в основной стабильной конфигурации
N16R8 не планируется.

## Первое включение

1. Включите устройство и дождитесь появления открытой Wi-Fi-сети
   `ESP32-Radio-XXXX`.
2. Подключитесь к ней с телефона или компьютера. Страница первоначальной
   настройки должна открыться автоматически.
3. Если captive portal не открылся, введите в браузере адрес `192.168.4.1`.
4. Выберите домашнюю Wi-Fi-сеть и укажите пароль. Перед сохранением устройство
   проверит подключение.
5. После успешной проверки устройство подключится к выбранной сети и отключит
   свою точку доступа. Его новый IP-адрес можно посмотреть в интерфейсе
   маршрутизатора.

Если основная Wi-Fi-сеть недоступна при загрузке, устройство снова поднимет
точку доступа для изменения настроек и продолжит попытки подключения.

## Возможности

- воспроизведение интернет-радиостанций MP3, AAC, FLAC, OGG Vorbis и Opus;
- поддержка плейлистов M3U и M3U8;
- защищённые HTTPS-потоки с обязательной проверкой TLS-сертификатов;
- отображение названия станции, ICY-метаданных и параметров аудиопотока;
- избранное, пользовательские станции и локальный рейтинг;
- эквалайзер, loudness, обработка низкого битрейта и расширение стереобазы;
- управление воспроизведением, громкостью и выбором станции;
- будильники с выбором радиостанции и плавным увеличением громкости;
- первоначальная настройка Wi-Fi через captive portal;
- автоматическая регулировка мощности Wi-Fi;
- ручное и автоматическое обновление прошивки и web-интерфейса;
- сохранение пользовательских настроек в отдельном разделе памяти.

Подробности новых версий находятся в
[истории изменений прошивки](docs/Software/firmware_changes.md).
