# Прошивка устройства

Первую установку прошивки на ESP32-S3 необходимо выполнять через
[**Espressif Flash Download Tool**](https://docs.espressif.com/projects/esp-test-tools/en/latest/esp32/production_stage/tools/flash_download_tool.html). После первичной установки обновлять прошивку и LittleFS можно через OTA в web-интерфейсе устройства.

## Настройки Flash Download Tool

- ChipType: `ESP32-S3`
- SPI MODE: `DIO`
- SPI SPEED: `80 MHz`
- FLASH SIZE: `16 MB`
- Все строки с образами должны быть включены флажками.
- Для чистой первой установки рекомендуется полностью стереть flash-память
  кнопкой `ERASE`.
- При миграции с `1.x` полное стирание запрещено, если требуется сохранить
  NVS и `/userdata`.

## Образы и адреса

Пути в таблице указаны относительно корня рабочего каталога проекта.

|     Offset | Файл                                        | Назначение                               |
| ---------: | ------------------------------------------- | ---------------------------------------- |
|   `0x0000` | `bootloader.bin`                            | Загрузчик                                |
|   `0x8000` | `partition-table.bin`                       | Таблица разделов                         |
|  `0x19000` | `ota_data_initial.bin`                      | Начальное состояние OTA                  |
|  `0x20000` | `ESP32-PCRadio.bin`                         | Основная прошивка                        |
| `0x620000` | `littlefs_image.bin`                        | LittleFS: WebUI, основной слот           |
| `0x718000` | `littlefs_image.bin`                        | LittleFS: WebUI, резервный слот          |

Второй LittleFS-раздел `storage_ota` находится по адресу `0x718000`. Оба
WebUI-раздела имеют размер 992 КиБ и при полной установке получают одинаковый
образ.
Оставшийся раздел `userdata` начинается с адреса `0x810000`.

## Порядок первой прошивки

1. Подключить устройство и выбрать его COM-порт.
2. Добавить в Flash Download Tool все шесть строк из таблицы и указать
   соответствующие offset.
3. Проверить настройки flash-памяти.
4. Выполнить `ERASE`.
5. Нажать `START` и дождаться успешного завершения записи.
6. Перезагрузить устройство.
7. Подключиться к `ESP32-Radio-XXXX` и выполнить первоначальную настройку Wi-Fi
   через captive portal. Суффикс образован из двух последних байтов MAC.

## Последующие обновления

После первой установки `ESP32-PCRadio.bin` и `littlefs_image.bin` обновляются
одной совместимой парой через OTA в web-интерфейсе. Пользовательский раздел
`/userdata` при этом не перезаписывается. Flash Download Tool для обычного
обновления больше не требуется.

Бинарные файлы и OTA-манифест публикуются непосредственно в корне ветки
`update`. Обновление между разными MAJOR-версиями выполняется через Flash
Download Tool, поскольку оно может требовать изменения таблицы разделов.
